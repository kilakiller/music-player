使用方法
──────────────────────────────

1. 双击 index-v6.html 用 Chrome / Edge 打开
2. 点「选择音乐文件夹」，选一个装歌的文件夹（一次就够）
3. 封面和歌词会自动出现，播放时歌词自动滚动高亮

文件命名规则（同名即配对）
──────────────────────────────
  song.mp3      音乐
  song.jpg      封面（也支持 png / webp）
  song.lrc      歌词（带时间轴，会自动滚动）

  没有单独封面时，会读取 mp3 里内嵌的专辑封面
  没有 .lrc 时，会读取 mp3 内嵌的 USLT 歌词标签（纯文本，不滚动）
  也可以整个文件夹放一张 cover.jpg 作为统一的默认封面

歌词文件格式（.lrc）
──────────────────────────────
  [00:00.00]第一句歌词
  [00:06.50]第二句歌词
  [00:13.00]第三句歌词

快捷键
──────────────────────────────
  空格      播放 / 暂停
  ← →      上一首 / 下一首
  L        打开曲目列表

目录说明
──────────────────────────────
  index-v6.html   当前版本（只用封面卡 + 歌词两块 UI）
  music/          示例素材，可以直接选这个文件夹试用
  covers/         示例封面
  index.html / index-v2 / v3 / v4 / v5   历史版本，可删
